# djannasobol.com

Landing site for **Anna Sobol** — DJ & producer.

Static single-page site (`index.html`). Hosted on a VPS; this repo is the source of truth for content and layout.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
```

## Deploy

Upload `index.html` to the web root on the server (nginx), e.g. `/var/www/djannasobol/`.

Do **not** put VPN secrets, SSH keys, or `.env` files in this repository.
